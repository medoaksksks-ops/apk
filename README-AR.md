# TITAN HUB — Android APK

هذا المشروع يغلّف ملف TITAN HUB V6.5 الأصلي داخل تطبيق Android باستخدام Capacitor، مع إبقاء صفحات HTML/CSS/JavaScript وطلبات الـ API الموجودة كما هي.

## استخراج APK تلقائيًا

1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build TITAN HUB APK** ثم **Run workflow**.
5. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `titan-hub-debug-apk` وفك ضغطه؛ ستجد `app-debug.apk`.
7. انقل APK إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من مصدر الملف.

## ملاحظات مهمة

- هذا APK تجريبي Debug للتثبيت والاختبار، وليس إصدار متجر Google Play موقّعًا.
- لم أغيّر روابط الـ API أو منطق تشغيل الفيديو داخل ملف الموقع.
- التطبيق يحتاج اتصال إنترنت للوصول إلى السيرفرات والخدمات الخارجية والخطوط.
- دعم التنزيلات داخل WebView قد يختلف عن المتصفح، خصوصًا التنزيلات التي تعتمد على CORS أو HLS؛ يلزم اختبارها على الجهاز وقد تحتاج ربطًا أصليًا بـ Android DownloadManager.
- لم أستطع إخراج APK مباشرة في بيئة العمل الحالية لعدم وجود Android SDK/Build Tools؛ سير العمل المرفق يبنيه على GitHub Actions ويتيح تنزيله كـ Artifact.
